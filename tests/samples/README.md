# Sample show output

The files directly in this folder were written by hand from typical Cisco
IOS output, not captured from our switches. Spacing and wording on IOSvL2
may be different. They are kept for the older tests.

Subfolders:

- `real/`: raw captures from the five IOSvL2 15.2 switches in GNS3. Only
  these count as verified samples. Passwords in `*_show_running_config.txt`
  are replaced with `<REDACTED>`.
  - Baseline (before the tool ran, 2 Nov): `SWx_<command>.txt`.
  - The tool's own logs (frozen, never regenerated by the tests):
    `run_20261103_113312.log` (first dry-run), `run_20261105_235328.log`
    (first real apply, all 5 SAVED), `run_20261106_014041.log` (TC09,
    SW3 rolled back), `run_20261106_014707.log` (dry-run after TC09).
    Tests cut the SSH output out with `conftest.log_block()`.
  - `SW1_*_after.txt`, `SW2_*_after.txt`: console captures (Solar-PuTTY,
    Windows) a few minutes after the real apply run. CRLF line ends, and the
    console wraps the `show vlan brief` port list. Kept raw: do not convert
    the line ends or edit them.
  - `SW2_flash_copy_and_gi01.txt`: flash copy prompts and SW2 Gi0/1 config (4 Nov).
- `transcribed/`: typed by hand from screenshots of real IOSvL2 output.
  The content is real, but spacing may differ. Each file says so in a
  `#` header.
- `synthetic/`: made-up variants of real layouts, built to test one
  specific parser behaviour. Never evidence of real switch output.
  (The hand-made `SW1_after_*` and `SW2_after_*` files were removed on
  6 Nov; the real post-apply output replaced them.)

To add a capture: save it as `real/<SWITCH>_<command>.txt` (for example
`SW2_show_run_int_gi0_1.txt`), add a test for it, and re-run `pytest`.
